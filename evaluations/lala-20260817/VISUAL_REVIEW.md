# LALA CUJ 시각 비교 분석 — 2026-08-17

## 방법과 범위

- **검토자:** Hermes Agent
- **방법:** CUJ case별로 BEFORE, 기존 Vibe AFTER, LALA, Nano Banana와 제공된 경우 FiveK를 같은 카드/시트에서 직접 육안 비교했다.
- **대상:** LALA 결과 114개. LUT 100개, Generate AI 14개.
- **평가 원칙:** Python 점수나 파일 크기는 품질 순위에 사용하지 않았다. 파일 무결성 확인에만 사용했다.
- **FiveK 한계:** 모든 case에 존재하지 않는다. 제공된 case에서만 자연스러운 보정 기준점으로 비교했다.
- **생성형 한계:** Generate AI 결과는 목적에 맞는 구도/가시성을 만들 수 있으나 원본 픽셀을 그대로 보존하는 결과가 아니다. 인물·텍스트·경계·세부 질감은 원본 크기로 확대 검수가 필요하다.

## 전체 결론

### LALA의 상대 우위

1. **구조 보존이 중요한 LUT 보정**
   - 대다수 LUT 결과는 사람·건물·음식의 배치와 원본 구도를 유지한다.
   - Nano Banana가 하늘·배경·빛·질감을 새로 만들거나 크게 바꾸는 case와 비교하면, LALA는 안전한 원본 보존 측면에서 낫다.
2. **크롭/피사체 중심 작업**
   - Generate AI를 선택한 10번 crop case는 LALA가 인물·음식·메인 피사체를 화면 중심으로 재구성해 원본보다 목적 적합성이 높았다.
3. **대화형 미세 조정**
   - 21번의 강도 절반, 은은한 톤다운, 자연스러운 마무리처럼 큰 변화가 목적이 아닌 작업에서 LALA의 절제된 변화는 장점이다.
4. **피부 리터치의 과장 억제**
   - 20번 Generate AI 결과는 저조도 인물 가시성을 개선하면서도 비교 시트상 과도한 플라스틱 피부는 상대적으로 적었다. 단, 고주파 질감 보존은 확대 검수가 필요하다.

### LALA의 상대 열세

1. **범용 노출·화이트밸런스·저노출 복원**
   - 02·03·05·06번에서 LALA는 변화량이 작고 중간톤이 평평해 보였다.
   - 특히 저노출/역광 scene에서 암부를 충분히 살리지 못해 Vibe와 Nano보다 피사체 가독성이 낮았다.
2. **스타일 LUT의 haze/저대비 경향**
   - 11~19번에서 LALA는 의도된 룩을 강하게 만들기보다 전체 대비와 채도를 누르는 방식으로 보이는 case가 많다.
   - 결과적으로 매트·빈티지·시네마틱·느와르 등의 서로 다른 룩이 분명히 분화되지 않고, 회색 막 또는 탈색으로 읽히는 경우가 있다.
   - 느와르에서는 특히 블랙 레벨과 대비가 부족해 Vibe의 더 뚜렷한 흑백 대비보다 열세였다.
3. **FiveK 대비 자연 보정 완성도**
   - FiveK가 있는 case에서 FiveK는 대체로 하이라이트 보존, 중간톤 분리, 피부/중립색의 균형이 더 자연스러웠다.
   - LALA는 과포화를 피하는 것은 장점이나, FiveK보다 깊이와 명료도가 부족했다.

### Nano Banana와의 비교

- Nano Banana는 밝기·채도·광원·하늘·분위기 변화가 더 강하고 즉시 눈에 띈다.
- 반면 하늘 교체, 흑백, 일부 스타일 작업에서 원본 장면을 단순화하거나 재구성하는 흔적이 보인다. 원본 보존 편집의 기준으로는 무조건 우위가 아니다.
- 따라서 **명확한 스타일/재구성이 필요하면 Nano Banana류 생성 모델**, **원본 동일성과 가역적 보정이 중요하면 LALA LUT**가 적합하다. 다만 현재 LALA LUT의 노출·톤 곡선은 보정이 필요하다.

## 근본 개선 우선순위

1. **LUT tone curve 재교정:** 블랙을 무작정 들어 올리는 매트 성향을 줄이고, scene-aware midtone contrast와 하이라이트 롤오프를 분리한다.
2. **노출/화이트밸런스 preset 재검증:** 저노출·역광·mixed light case에서 피사체 가시성과 중립색을 우선하는 calibration TC를 만든다.
3. **스타일별 분화:** clean/neutral, matte, vintage, cinematic, noir의 contrast·saturation·hue behavior를 서로 다르게 검증한다. 모든 스타일이 같은 저대비/탈색으로 수렴하면 안 된다.
4. **LUT와 Generate AI routing 검증:** crop, 국소 피부 리터치, 복잡한 구조 변경은 Generate AI가 맞다. 단 생성 결과에는 얼굴·문자·경계 확대 검수를 추가한다.
5. **승인 전 visual gate:** 새 LUT calibration은 이 HTML 카드와 원본 크기 대표 case를 사람이 직접 보고 승인한다. 자동 지표는 누락/무결성 보조용으로만 사용한다.
